Problema real

Um e-mail fixo funciona quantas vezes?

Frágil
const email = 'aluno@email.com'

A segunda execução encontra o usuário existente.

Repetível
const email =
  `aula4.${Date.now()}@email.com`

Cada execução recebe um identificador novo.

Organização

before ou beforeEach?

before()

Executa uma vez antes do grupo.

criar o usuário do login
beforeEach()

Executa antes de cada cenário.

abrir /cadastro ou /login

Dados compartilhados precisam ser controlados. A interface deve começar conhecida.

Novos recursos

Mais ferramentas para verificar

cy.contains()localiza pelo papel e texto

.and()encadeia outra asserção

.eq()seleciona um item da lista

have.lengthverifica uma quantidade

cy.get('.alert-success')
  .should('be.visible')
  .and('contain', 'sucesso')

cy.contains('button', 'Entrar')
  .should('be.visible')
Parte 1 • Cadastro guiado

Vamos construir juntos.

Abra 01-cadastro-guiado.cy.js e acompanhe a implementação.

Mapeamento da tela

Seletores do cadastro

cy.get('#nome')
cy.get('#email')
cy.get('#senha')
cy.get('input[type="submit"]')

O seletor deve identificar o elemento pelo seu papel, não pela posição visual.

CAD-01 • Cenário feliz

Cria usuário com dados válidos

const email = `cadastro.ok.${Date.now()}@email.com`

cy.get('#nome').type('Aluno Aula 4')
cy.get('#email').type(email)
cy.get('#senha').type('Senha123')
cy.get('input[type="submit"]').click()

Como provar que funcionou?

Verificação completa

Mensagem + interface resultante

cy.get('.alert-success')
  .should('be.visible')
  .and('contain', 'Usuário inserido com sucesso')

cy.contains('button', 'Entrar')
  .should('be.visible')

A mensagem confirma a resposta; o formulário de login confirma o estado final.

Parte 2 • Desafio em duplas

Agora protejam o login.

A conta será preparada uma vez. Cada tentativa começará em uma página limpa.

Pré-condição do login

Para entrar, o usuário precisa existir

const usuario = {
  nome: 'Aluno Aula 4',
  email: `login.aula4.${Date.now()}@email.com`,
  senha: 'Senha123',
}

before(() => {
  // cadastrar usuario uma vez
})
LOG-01 • Cenário feliz

Credenciais válidas abrem o sistema

cy.get('#email').type(usuario.email)
cy.get('#senha').type(usuario.senha)
cy.contains('button', 'Entrar').click()

Qual mensagem deve aparecer?

Qual elemento prova que o usuário está autenticado?

LOG-02 • Falha

E-mail existe, mas a senha está errada

cy.get('#email').type(usuario.email)
cy.get('#senha').type('SenhaIncorreta')
cy.contains('button', 'Entrar').click()

Esperado: erro de autenticação e permanência no login.

LOG-03 • Falha

Dois campos vazios, dois erros

cy.get('.alert-danger').should('have.length', 2)

cy.get('.alert-danger').eq(0)
  .should('contain', 'Email é um campo obrigatório')

cy.get('.alert-danger').eq(1)
  .should('contain', 'Senha é um campo obrigatório')
